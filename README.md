# akdas-site

Project website for AKDAS: seismic tomography of the Alaska subduction zone using DAS. Built with [Quarto](https://quarto.org) and published to GitHub Pages on every push to `main`.

- **Add a checkerboard run:** drop a folder into `results/runs/` (see [adding-results.qmd](adding-results.qmd)).
- **Preview locally:** `pip install pyyaml`, install Quarto, then `quarto preview`.
